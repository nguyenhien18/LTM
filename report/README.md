# Báo cáo bài tập lớn

Thư mục này dành cho báo cáo của đề tài **Hệ thống thi trắc nghiệm qua mạng LAN theo mô hình Client–Server**, theo cấu trúc project giảng viên khuyến nghị.

Hiện chỉ giữ file hướng dẫn để thư mục xuất hiện trên GitHub. Báo cáo Word/PDF, bản nháp, hình và dữ liệu thực nghiệm của báo cáo được giữ cục bộ, chưa đưa lên repository.

Khi hoàn thiện bộ nộp, bổ sung bản báo cáo cuối tại `report/report.pdf`.
