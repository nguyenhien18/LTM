# Tài liệu tham khảo kỹ thuật

Các nguồn dưới đây dùng cho phần giao thức, xử lý đồng thời, lưu trữ, kiểm thử và khảo sát hệ thống liên quan. Khi đưa vào báo cáo, gắn số trích dẫn ở đúng đoạn sử dụng.

1. IETF, [RFC 9293 — Transmission Control Protocol](https://www.rfc-editor.org/rfc/rfc9293.html).
2. Oracle, [Java SE 21 API — Socket](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/net/Socket.html).
3. IETF, [RFC 8259 — The JavaScript Object Notation Data Interchange Format](https://www.rfc-editor.org/rfc/rfc8259.html).
4. JSON Lines, [Documentation for the JSON Lines Text Format](https://jsonlines.org/).
5. Oracle, [Java 21 Core Libraries — Virtual Threads](https://docs.oracle.com/en/java/javase/21/core/virtual-threads.html).
6. Oracle, [Java SE 21 API — Semaphore](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/concurrent/Semaphore.html).
7. Hibernate, [Hibernate ORM 6.6 User Guide](https://docs.hibernate.org/orm/6.6/userguide/html_single/).
8. Oracle, [MySQL 8.0 Reference Manual — InnoDB Transaction Model](https://dev.mysql.com/doc/refman/8.0/en/innodb-transaction-model.html).
9. MoodleDocs, [Moodle 4.5 — Quiz Settings](https://docs.moodle.org/405/en/Quiz_settings).
10. Safe Exam Browser, [About Overview](https://safeexambrowser.org/about_overview_en.html).
11. OpenJFX, [JavaFX 21 API — Stage](https://openjfx.io/javadoc/21/javafx.graphics/javafx/stage/Stage.html).
12. H2 Database, [Features](https://www.h2database.com/html/features.html).

Mã nguồn của nhóm nằm trong `src/`. Bằng chứng chạy kiểm thử và đo tải nằm tại [results](results/README.md); đây là dữ liệu của dự án, tách khỏi nguồn tham khảo bên ngoài.
